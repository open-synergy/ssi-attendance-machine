===================================================
Attendance Machine - Documenso Signing Integration
===================================================

Glue module that adds Documenso digital signing support to the Attendance
Machine Import document via ``mixin.documenso_signing_approval``.


Work Instruction
================

* `Attendance Machine Import <docs/attendance_machine_import/index.html>`_


Bug Tracker
===========

Bugs are tracked on `GitHub Issues
<https://github.com/open-synergy/ssi-attendance-machine/issues>`_. In case of

feedback.
