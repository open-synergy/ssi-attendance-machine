# Delete Attendance Machine

> **Module:** ssi_attendance_machine
>
> **Model:** `attendance_machine`
>
> **Menu:** Human Resource > Configuration > Configuration > Attendance Machines
>
> **Actor:** user in group _Attendance Machine_
>
> **Requires:** `01-create`

## Pre-Condition

- **Access:** User is in group _Attendance Machine_.

## Flow

1. Open the **Human Resource > Configuration > Configuration > Attendance Machines**
   menu.
2. Open the record to delete.
3. Click **Action** > **Delete**.
4. Click **OK** to confirm.
5. Click the **Attendance Machines** breadcrumb link to return to the list.

## Post-Condition

- The record is permanently removed from the system.
- The deleted record no longer appears in the Attendance Machines list.
